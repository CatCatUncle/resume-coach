# 简历教练

[English](README.md) | 简体中文

一个面向开发者猫叔及其粉丝的简历撰写与求职辅导技能，帮助用户把真实经历整理成清楚、贴合岗位的简历，并准备好在面试中讲清楚自己的经历。

## 一句话开始

不用先准备好简历，也不用填长问卷。直接发简历、零散笔记，或先讲一段经历就行。

可以这样说：

- **修改简历：**“帮我改一下简历。我想投运营岗，这是简历和 JD。”
- **从零开始：**“我还没有简历，想找客服工作。我做过餐饮店收银和排班。”
- **转行求职：**“我做了五年老师，想转产品运营，帮我看看哪些经验能用。”
- **探索方向：**“我做过这些事，也不喜欢长期出差，帮我一起理理适合投什么岗位。”
- **只改一段：**“帮我把这段项目经历改清楚，别写得太夸张。”

技能每轮只问少量问题，会先用已有信息推进，并把未知事实标出来让用户核对。

## 能做什么

- 诊断、修改或从零撰写简历
- 根据真实 JD 定制简历重点和表达
- 帮助应届生和转行者寻找真实、相关的经历证据
- 区分直接匹配、可迁移经验、真实缺口和待确认信息
- 按需准备面试故事和一个可执行的下一步

## 可信与隐私

- 不编造经历、技能、证书、数据或结果。
- 不夸大个人在团队成果中的贡献。
- 只有用户确认了来源和口径的数据，才写成具体数字。
- 不承诺 ATS 通过、面试邀约、薪资或录用结果。
- 不混用不同用户的简历资料。
- 真实简历、候选人资料和生成文档保存在本仓库之外。
- 将粉丝简历用于公开内容前，须先取得明确同意并充分脱敏。
