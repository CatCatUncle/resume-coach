## 快速开始

1. 按 [OpenWorkBuddy 快速开始](https://github.com/CatCatUncle/openworkbuddy#quick-start) 安装或启动应用，并连接可用模型。
2. 在 OpenWorkBuddy 项目目录安装本技能：

   ```bash
   git clone https://github.com/CatCatUncle/resume-coach.git skills/resume-coach
   ```

3. 刷新技能列表，选择 `/resume-coach`，直接发：

   ```text
   帮我修改这份简历，我想投运营岗，下面是简历和目标 JD。
   先指出最重要的三个问题，再帮我改写；不要编造经历和数据，
   不确定的地方标出来让我确认。
   ```

还没有简历？先讲一段工作、项目或校园经历就行。技能会每次问少量问题，用已有信息开始整理。

技能入口是 [`SKILL.md`](SKILL.md)，也可以放到其他兼容 Agent 的技能目录中使用，不强制依赖 OpenWorkBuddy。

## 能帮你做什么

| 你的情况 | 技能怎么帮你 |
|---|---|
| 已有简历，想改好 | 先找最重要的问题，再改清楚相关段落 |
| 没有简历，不知道怎么开始 | 从已确认的经历整理草稿，不用先填长表 |
| 想投某个具体岗位 | 把真实 JD 与经历证据对应起来，列清匹配项和缺口 |
| 想转行 | 找可迁移的经验，不把措辞润色当成资历补齐 |
| 准备面试 | 整理本人能讲清的经历故事，标出还需核对的事实 |

### 也可以这样开始

- **只改一段**：“帮我把这个项目写清楚，别夸大我个人的贡献。”
- **没有业绩数字**：“帮我找能核实的交付和证据，不要凑数字。”
- **还没确定方向**：“这是我的经历和工作偏好，先帮我比较几个可能适合的岗位。”

## 可信与隐私

- 不编造经历、技能、证书、数据或结果；未知事实由用户确认。
- 如实表达个人贡献，不混用不同候选人的信息。
- 不承诺 ATS 通过、面试邀约、薪资或录用结果。
- 真实简历、候选人资料和生成文档保存在本仓库之外；公开案例须先取得明确同意并充分脱敏。
- 本地应用也可能调用云端模型或连接器，发送敏感资料前请检查所选服务和数据设置。
